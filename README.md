# 📚 StudySphere

> **A modern digital study management platform designed to help students organize, manage, and access their academic resources in one place.**

StudySphere is a web-based student productivity and resource management application built with **React, TypeScript, Firebase, and Tailwind CSS**. It provides a centralized platform for managing study materials and academic resources through a clean and responsive interface.

## ✨ Features

* 🔐 **User Authentication** — Secure user authentication using Firebase
* 📁 **File Management** — Upload and manage academic resources
* ☁️ **Cloud Storage** — Store study materials securely using Firebase
* 📱 **Responsive UI** — Works across desktop, tablet, and mobile devices
* 🔔 **Toast Notifications** — Real-time feedback for user actions
* 📤 **Drag & Drop Uploads** — Easy file uploading using React Dropzone
* ⚡ **Fast & Modern Interface** — Built with React and Vite
* 🎨 **Utility-First Styling** — Responsive UI built using Tailwind CSS

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/)
* npm
* Git

### 1. Clone the Repository

```bash
git clone https://github.com/shishirmishra9918-cmd/StudySphere.git
```

### 2. Navigate to the Project

```bash
cd StudySphere
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the project root and add the required Firebase/API configuration.

```env
# Add your project configuration here
```

> **Note:** Never commit private API keys, service credentials, or other secrets to GitHub.

### 5. Start the Development Server

```bash
npm run dev
```

The application will be available at the local URL provided by Vite.
